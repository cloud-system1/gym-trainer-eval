1. Back up your current Google spreadsheet and Apps Script manually before changing anything.
2. Backend preserves the existing five-column layout: Timestamp, Customer ID, Trainer Name, Rating, Marks. Keep the existing headers and data.
3. In Apps Script, add Code.gs. Under Project Settings > Script Properties set SPREADSHEET_ID (from sheet URL), SHEET_NAME (exact tab name), ADMIN_PASSWORD (same as results.html SECRET_PASSWORD). Deploy as web app, execute as owner, access Anyone (if permitted). Authorize spreadsheet creation. Use one deployment for both pages. Disable old write deployments to prevent writes during backup.
4. Paste the new /exec URL into config.js. Upload index.html, results.html and config.js to GitHub. Keep existing assets.
5. Test on a COPY of the live sheet first: submit all six ratings, verify separate Not Familiar counts, confirm report navigation, clear and open backup. Verify original headers remain and backup contains every prior row. Test incorrect password and failed backup. Browser CORS and Apps Script authorization must be verified in deployment.
Security: existing report password is embedded in public HTML; this is not secure authentication. Backend checks the password for clearing but anyone with source can read it. Do not use this as strong admin protection; restrict access or implement real server-side authentication before production. Backups are created in the executing owner's Google Drive. Existing report endpoint is public; this replacement retains that behavior.
